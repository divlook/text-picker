📢 What is Text Picker?

Text Picker is a powerful Chrome extension that lets you quickly and easily extract text you cannot select on web pages. It accurately detects the text you need, and its intuitive interface makes it easy for anyone to use.

Use the selection area to locate and copy the text you need. For example, you can extract an article title or important data from a web page that does not let you select and copy its text.


✨ Key Features

1. Select an area
   - Click the part of the page you want to extract text from to create a selection box.
   - Easily adjust its size and position. The selection area starts at 300 × 150px, and you can reduce its width and height to a minimum of 20px each.
2. Copy text with one click
   - Click [Copy Text] to copy the selected text.


🚀 How to Use

1. Click the Text Picker icon in the Chrome toolbar.
2. Use your mouse to select the area you want to extract text from, then adjust the selection area.
3. Click [Copy Text] to copy the text.
4. When you are finished, click [Quit] to exit.


⚠️ Limitations

- Some text may not be detected correctly if the page has an abnormal DOM structure.
